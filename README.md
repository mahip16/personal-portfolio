# Personal Portfolio - Mahi Patel

My personal portfolio built with React + Vite, deployed on Vercel.

🌐 **Live:** https://mahi-patel.vercel.app/

## Built With
- React + Vite
- CSS
- Deployed on Vercel

## Sections
- **Home** - intro and CTA
- **About** - timeline of projects and milestones
- **Skills** - tech stack in terminal style
- **Projects** - F1 Race Predictor + SuppleScan deep dives

## Run Locally
```bash
npm install
npm run dev
```
